# PeachCheck dependencies. Per Congressional App Challenge rules, every open-source
# library is documented here against what the team wrote itself (see README.md,
# "What the team wrote vs. what libraries do").

# --- Provenance layer (peachcheck/layers/provenance.py) ---
# Reads the JUMBF container and verifies COSE signatures; the team wrote the
# four-state routing decision logic on top of it.
c2pa-python

# --- Forensics layer (peachcheck/layers/forensics.py) ---
# Image I/O + array math. ELA and FFT signal logic is team-written on these.
Pillow
numpy
# Pretrained AI-image classifier (umm-maybe/AI-image-detector). Pretrained weights
# only — the model is never trained in-house; see check_ml_classifier.
transformers
torch

# --- Measurement layer (peachcheck/layers/measurement.py) ---
# OCR engines for disclosure bounding boxes. pytesseract is used when the tesseract
# binary exists (the Docker image installs it); easyocr is the pure-pip fallback for
# local dev machines. All threshold arithmetic is team-written.
pytesseract
easyocr

# --- API (app.py) ---
fastapi
uvicorn
python-multipart
# Social/video URL resolution + server-side frame extraction for normal post links.
yt-dlp
imageio-ffmpeg

# --- Tests ---
pytest
httpx
